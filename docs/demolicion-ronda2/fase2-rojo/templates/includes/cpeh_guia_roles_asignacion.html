Guía de este tablero — asignación de casos

Este tablero permite al coordinador distribuir casos ROJO entre inspectores y revisores. Para el flujo general del sistema, roles detallados y tutorial por perfil, consulte la sección «Tutorial del sistema» en el panel de inicio.

{% include "includes/cpeh_guia_flujo_core.html" %}

Cómo usar este tablero

  1. Revise la carga por usuario (tarjetas superiores) para equilibrar trabajo.
  2. Filtre casos sin inspector o sin revisor con los botones rápidos.
  3. Marque casos con la casilla y use la barra amarilla para asignación masiva de inspector y/o revisor.
  4. Para un solo edificio, use los selectores de la columna Asignar y pulse OK.
  5. Seleccione casos y pulse Excel lote (una fila por edificio) o Excel informes (una pestaña por edificio) para entregar plantillas al equipo.
  6. El inspector verá sus casos en Admin → Casos ROJO; al completar el informe lo envía a revisión.
