0. Cómo leer esta guía

Está pensada para quienes conocen Python básico (variables, funciones) y quieren entender qué hay montado, dónde está y qué comandos ejecutar. No hace falta ser experto en Django: cada bloque explica el concepto antes del comando.

  • Operadores / campo — usen «Sobre esta fase», «Tutorial del sistema» y «Guía del informe».
  • Desarrolladores junior — lean esta sección completa y practiquen los comandos en orden.
  • Documento hermano — «Propuesta sistema seguimiento Fase II — guía equipo junior» (Word 27/08/2026): aquí está la misma línea con más detalle operativo del despliegue actual.

1. ¿Qué es este sistema?

Aplicación web interna (Django) para el seguimiento Fase II de edificaciones etiqueta ROJO: una ficha por edificio con 11 secciones numeradas, dictamen D1–D4, estados de revisión y exportación PDF. Reemplaza hojas sueltas / Excel como registro maestro operativo (el Excel sigue siendo plantilla de referencia).

Decisión de marco: Django porque el problema es CRUD + usuarios + workflow + PDF, no un tablero BI. El equipo ya usa Python (Habitable, scripts Excel). Django Admin permite operar antes de tener un wizard bonito.

7. Comandos — guía por escenario

7.1 Primera conexión SSH (verificar que llegaste bien)

pwd && whoami && hostname
ls -la ~/
ls -la ~/apps/fase2-rojo/
python3 --version

7.2 Entrar al proyecto y activar Python virtual

El venv aísla las librerías del proyecto. Siempre activarlo antes de manage.py.

cd ~/apps/fase2-rojo
source .venv/bin/activate
which python   # debe apuntar a .../fase2-rojo/.venv/bin/python

7.3 Comandos Django habituales

python manage.py check              # ¿Configuración OK?
python manage.py showmigrations     # migraciones aplicadas
python manage.py migrate            # aplicar cambios de BD
python manage.py createsuperuser    # nuevo admin (solo si hace falta)
python manage.py cargar_franco_mar  # recargar caso ejemplo ID 171818
python manage.py shell              # consola Python con Django cargado
python manage.py collectstatic --noinput   # CSS/logos → staticfiles/

7.4 Si la web responde 503 (Gunicorn caído)

~/apps/fase2-rojo/run/ensure-running.sh
curl -s http://127.0.0.1:8000/api/health/

Con sudo disponible: sudo systemctl restart fase2-rojo

7.5 Probar PDF de un caso

# En navegador (logueado como admin):
# http://190.169.110.9/admin/inspecciones/casorojo/1/pdf/
# (1 = pk interno; hab_id puede ser 171818)

7.6 Desplegar cambios desde PC Windows (equipo con llave)

# En la copia local del repo BI-Habitable:
python docs/demolicion-ronda2/server-bootstrap/deploy_dashboard.py

Ese script sube plantillas, CSS, admin, views y ejecuta collectstatic + reinicio Gunicorn.
